# The GTM Table Agent Guide

## Project

This project is The GTM Table, a curated Bay Area GTM community.

## Stack

- Next.js
- Tailwind CSS
- Vercel
- beehiiv

## Product direction

Keep the first version as a single-page validation landing page.

Do not add any of the following unless explicitly requested:

- Authentication
- Database
- Payments
- Member portal
- Event management

Use placeholder links for beehiiv until final beehiiv URLs are provided.

## Messaging guidelines

Use messaging that feels:

- Premium
- Practical
- Curated
- Operator-led

Avoid generic networking, community, course, or webinar language. Position The GTM Table as a high-signal, curated room for Bay Area enterprise GTM operators and founders to exchange practical, field-tested playbooks.

## Code and content guidelines

- Keep components clean and easy to reason about.
- Keep copy easy to edit.
- Prefer simple, maintainable structure over premature abstraction.
- Do not overbuild the first version.

## Verification

After meaningful code changes, always run lint and build commands when available.
